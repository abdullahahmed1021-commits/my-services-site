# موقع خدمات عبدالله أحمد — المشروع التجاري الثالث

موقع عربي من ثلاث صفحات مستقل عن الموقع الشخصي ومعرض الأعمال.

## الصفحات
- index.html : الرئيسية والتعريف بالخدمات وبعض لقطات من الأعمال.
- services.html : تفاصيل 4 مجالات خدمية مبنية على السيرة الذاتية.
- contact.html : التواصل عبر البريد الإلكتروني.
- style.css : تنسيق مشترك متجاوب مع الجوال.
- assets/images/ : صور WebP ثابتة مستخرجة من فيديوهات الأعمال التي قدمها صاحب المشروع.

## التشغيل
افتح index.html في أي متصفح. الروابط بين الصفحات تعمل بدون إنترنت؛ فتح البريد يتطلب تطبيق بريد مضبوطًا.

## النشر
1. ارفع محتويات المجلد (وليس المجلد نفسه) إلى مستودع GitHub عام مستقل، وليكن abdullah-services-site.
2. تأكد أن index.html موجود مباشرة في جذر المستودع، وباقي الملفات والمجلدات بجواره.
3. اربط المستودع بمشروع Cloudflare Pages واختر إعدادات بناء فارغة، ومجلد إخراج الجذر إن طُلب.
4. افتح الصفحات الثلاث وتحقق من الصور والروابط من الهاتف.

## ملاحظة
هذا موقع تعريفي للخدمات وليس نظامًا لاستقبال المدفوعات أو الحجوزات. زر البريد يفتح برنامج البريد ولا يخزن رسائل على الموقع. لم تُدرج أسعار أو شهادات عملاء أو خدمات غير موثقة.
